# Intervwd

AI voice interviews for every hiring round. Companies set up jobs and rounds, candidates join through an invite link, an AI interviewer runs a structured interview tailored to their CV, and recruiters review scored reports and decide. Recruiters can also run their pipeline hands-free on Alexa+.

Live app: https://intervwd.com (in progress)

Built for the [Build, Ship, Shape: Amazon Developer Hackathon](https://amazonappdev2026.devpost.com/), Alexa+ track.
